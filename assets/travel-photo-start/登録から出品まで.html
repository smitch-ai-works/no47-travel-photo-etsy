旅写真：登録から出品まで

ショップを開く

  1. アカウント
    Etsy.com/sell → Get started。PCブラウザで開始します。
  2. ショップ設定
    言語・国・通貨・ショップ名を設定します。
  3. 受取口座
    日本の販売者はPayoneer経由でEtsy Paymentsを設定します。
  4. 本人確認
    Etsy・Payoneerの画面で指定された本人確認を行います。
  5. 請求と手数料
    請求方法・表示される開店費用を確認します。
  6. ショップ開店
    登録内容と規約を確認し、自分で公開操作を行います。

商品を登録する

  1. Shop Manager → Listings → Add a listing
  2. カテゴリを選び、商品タイプをDigital filesへ。
  3. 商品画像と、購入者へ渡す写真ファイルを分けて登録。ダウンロード用は最大5ファイル、各20MB。
  4. 商品名・説明・タグ・価格など必要項目を入力。
  5. Save as Draftで保存し、入力内容と購入者用ファイルを確認。
  6. 手数料と規約を確認し、自分でPublishを選ぶ。

写真・英語・登録内容の点検に同梱の指示文とメモを使ってください。
